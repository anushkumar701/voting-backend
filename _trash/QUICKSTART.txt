E-VOTING SYSTEM - QUICK START

1. START GANACHE (Port 7545)
2. DEPLOY CONTRACT (Remix IDE)
3. LOAD CONTRACT: the server will try to load it automatically if you
   set the `CONTRACT_ADDRESS` env var or drop the address in a file called
   `contract_address.txt`.  Otherwise call the API:
   curl -X POST http://localhost:5000/api/load-contract \
     -H "Content-Type: application/json" \
     -d '{"contract_address": "0xYOUR_CONTRACT_ADDRESS"}'
   (the address is then saved to `contract_address.txt` for next time)

4. RUN: START.bat

WORKFLOW:
Admin → Create Election (CREATED status)
Admin → Activate Election (ACTIVE status) ← REQUIRED FOR VOTING
Voter → Cast Vote (only works if ACTIVE)
Admin → Close Election (CLOSED status)
Admin → Archive Election (ARCHIVED status)
